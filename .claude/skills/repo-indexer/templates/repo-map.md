# Repo map

Copy this into the target repository at `.agentteam/repo-map.md`. Generated by the indexer,
reviewed once by a human, then regenerated on merge to main.

This file says **where to look and what the rules are**. It never says what the code currently
does — that comes from reading the code at task time. Anything here can be stale; anything read
live cannot.
